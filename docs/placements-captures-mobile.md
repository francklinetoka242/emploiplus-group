# Emplacements recommandés pour ajouter des captures d’écran du site sur mobile

Aucune modification de code n’a été faite.

## Vue d’ensemble

Après avoir parcouru les principales pages du site, les meilleurs endroits pour intégrer des captures d’écran de l’affichage sur mobile sont ceux où le contenu est déjà visuel, simple à comprendre et fortement orienté expérience utilisateur.

## Recommandations prioritaires

### 1. Page d’accueil : très bon emplacement principal

Emplacement conseillé :
- juste sous la section hero/CTA,
- ou entre la section “Nos services” et la section “Dernières actualités”.

Pourquoi :
- c’est la page la plus visitée,
- elle donne une première impression forte,
- elle permet de montrer rapidement que le site est utilisable et agréable sur mobile.

Idéal pour montrer :
- la navigation mobile,
- l’architecture des sections,
- l’expérience de consultation des services.

### 2. Page Services : emplacement naturel pour illustrer les parcours

Emplacement conseillé :
- à côté de chaque section “Candidat” et “Entreprise”,
- ou dans la zone déjà occupée par les visuels illustratifs.

Pourquoi :
- la page est déjà pensée comme une présentation de parcours et de solutions,
- les captures mobile peuvent renforcer la compréhension des expériences utilisateur,
- le code de la page accueille déjà des blocs de contenu visuel et des appels à l’action, ce qui rend l’intégration naturelle.

Idéal pour montrer :
- le parcours candidat,
- la navigation entre les solutions RH,
- l’affichage compact des contenus sur petit écran.

Observation supplémentaire :
- les sous-pages de services, comme celles orientées “Hub Emploi & Recrutement”, contiennent déjà des sections avec images et mises en avant de services ; ce sont d’excellents points d’insertion pour des captures de mobile si vous souhaitez montrer un parcours plus détaillé.

### 3. Page Offres d’emploi : très pertinent pour un usage mobile réaliste

Emplacement conseillé :
- au-dessus de la liste des offres,
- ou juste après le bloc de recherche/filtres.

Pourquoi :
- cette page a un vrai besoin de lisibilité mobile,
- les filtres et la présentation des offres sont des éléments très adaptés à une capture de type “mobile-first”.

Idéal pour montrer :
- la recherche d’offres,
- les filtres sur téléphone,
- la lecture des fiches d’offres dans un format compact.

### 4. Page Contact : bon endroit pour montrer l’expérience de prise de contact

Emplacement conseillé :
- à côté du formulaire de contact,
- ou juste sous l’en-tête de la page, avant la section d’information.

Pourquoi :
- la page est déjà structurée autour d’un parcours simple,
- une capture mobile peut montrer que le formulaire reste clair et accessible.

Idéal pour montrer :
- le formulaire sur mobile,
- la présentation des coordonnées,
- la facilité de contact depuis un téléphone.

## Emplacements à éviter ou à réserver

Les zones suivantes sont moins pertinentes pour des captures mobile :
- le footer,
- les pages légales / politiques,
- les sections purement textuelles sans contexte.

Ces espaces peuvent être utiles pour des éléments de support, mais ils ne sont pas aussi efficaces pour valoriser une expérience mobile.

## Meilleur ordre de priorité

1. Page d’accueil
2. Page Services
3. Page Offres d’emploi
4. Page Contact

## Recommandation finale

Si vous voulez un impact visuel fort, le meilleur choix est de placer une capture mobile sur la page d’accueil, puis de compléter avec des captures sur les pages Services et Offres d’emploi. Cela permet de montrer à la fois la présence générale du site et les parcours les plus importants pour l’utilisateur.
